# Codex 第一阶段施工单：基金零基础学习平台

## 任务定位

本阶段不是重写 MarketSim，也不是继续扩张 AI 投研功能。

目标是在现有项目上增加一个最小可用的“学习首页 + 课程列表 + 课程详情 + 小测 + 学习进度”，让零基础用户能够完成第一节基金课程。

必须先阅读：

```text
docs/FUND_LEARNING_PRODUCT_NORTH_STAR.md
docs/FUND_LEARNING_CURRICULUM_V1.md
```

任何新增功能与以上两份文档冲突时，以上述文档为准。

## 分支要求

只在以下分支工作：

```text
feature/fund-learning-platform
```

不要继续向 `feature/ai-fund-backtester` 写学习平台代码。
不要修改 `main`。
不要合并 PR。

开始前执行：

```powershell
git fetch origin
git checkout feature/fund-learning-platform
git pull origin feature/fund-learning-platform
git status
```

## 不从零重写

必须复用：

- FastAPI 启动方式；
- 原有登录系统；
- 原有前端基础样式；
- 基金数据接口；
- 历史回测模块；
- 模拟账户；
- 演示模式。

禁止：

- 新建第二套前后端框架；
- 引入 React、Vue、Next.js 等新框架；
- 重写登录和数据库；
- 删除原有功能；
- 同时做云部署、支付、会员或商业化；
- 自动生成买卖指令；
- 继续扩张基金经理人格或多 Agent 页面。

## 第一阶段页面结构

第一阶段只增加三个页面状态：

```text
学习首页
课程列表
课程详情
```

可以继续使用现有单页应用模式，不需要建立复杂路由系统。

### 学习首页

显示：

- 欢迎标题；
- 当前完成课数；
- 总课数；
- 下一节推荐课程；
- “继续学习”按钮；
- 三个工具入口：基金案例、历史回测、模拟训练；
- 固定风险提示。

### 课程列表

第一版只显示 6 节 MVP 课程：

1. 基金到底是什么；
2. 常见基金类型；
3. 收益率不能单独看；
4. 最大回撤是什么；
5. 如何分析一只基金；
6. 回测是什么。

每张课程卡显示：

- 章节编号；
- 标题；
- 预计学习时间；
- 一句话简介；
- 未开始 / 学习中 / 已完成；
- 开始或继续按钮。

### 课程详情

每节课程必须支持：

- 返回课程列表；
- 标题和预计学习时间；
- 一句话解释；
- 3～5 个短内容段落；
- 一个生活化例子；
- 一个常见误区；
- 两道单选题；
- 提交答案；
- 显示正确答案和简短解释；
- 完成本课；
- 进入下一课；
- 关联工具入口。

## 数据结构

建议新增：

```text
frontend/learning-content.js
frontend/learning.js
frontend/learning.css
```

## 学习进度

第一阶段使用 localStorage 保存，不改数据库。

建议键名：

```text
marketsim_learning_progress_v1
```

建议结构：

```javascript
{
  completedLessons: ["fund-basics-01"],
  quizResults: {
    "fund-basics-01": {
      score: 2,
      total: 2,
      submittedAt: "2026-07-11T12:00:00Z"
    }
  },
  lastLessonId: "fund-basics-01"
}
```

要求：

- 刷新页面后进度仍然存在；
- 不同浏览器设备暂时不要求同步；
- localStorage 数据损坏时自动恢复为空进度，不能白屏；
- 完成课程前不强制要求答对全部题，但必须提交过小测；
- 完成状态必须可撤销或重学。

## 导航调整

在现有底部导航中新增或调整一个明确的“学习”入口。

学习应成为默认主入口，但不要删除原有功能。

建议导航优先级：

```text
学习
基金案例
回测实验
模拟训练
我的
```

原有资讯、自选、系统等入口可以暂时保留在二级区域或“更多”，但本阶段不要做大规模导航重构。

## 多 Agent 和研究模块处理

本阶段不要继续开发 `backend/ai_research/`。

要求：

- 默认学习流程不调用 `/api/ai-research/{fund_code}`；
- 学习首页不展示 Agent 评分；
- 课程页面不出现“组合经理建议买入”；
- 不删除现有实验代码，但保持默认关闭或隐藏；
- 不修改它，除非它导致学习页面无法运行。

## 回测模块处理

回测继续保留，但改成学习工具入口，文案使用：

```text
历史回测实验
用过去数据观察一套规则曾经如何表现
```

不要使用：

```text
AI 推荐买入
未来收益预测
稳赚策略
```

本阶段不需要重写回测引擎，只需保证学习页面可以跳转到现有回测页面。

## 第一批课程内容

请根据 `FUND_LEARNING_CURRICULUM_V1.md` 完整写出前 6 节课的实际内容，不能只放占位符。

每节课：

- 正文总字数建议 400～900 个中文字符；
- 两道题必须与正文直接相关；
- 答案解释应让错误用户知道为什么错；
- 文案适合零基础，不堆砌专业术语；
- 不引用无法核实的收益数字；
- 不提供具体基金买卖建议。

## 样式要求

沿用当前项目风格，不重做整套 UI。

要求：

- 课程正文最大宽度适合阅读；
- 正文行高不低于 1.7；
- 手机端 390px 宽度不横向溢出；
- 课程卡在手机端单列；
- 小测按钮易点击；
- 正确、错误状态不仅依赖颜色，还要有文字；
- 底部导航不能遮挡课程内容；
- 免责声明不能遮挡操作按钮。

## 无障碍和稳定性

- 按钮必须使用 `button`；
- 单选题需要 label；
- 动态状态使用清晰文字；
- 对 localStorage 操作使用 try/catch；
- DOM 元素不存在时不能导致整个脚本停止；
- 防止重复绑定事件；
- 不使用内联 onclick；
- 不把用户输入直接写入 innerHTML；
- 不影响普通模式和演示模式。

## 演示模式

学习页面也要支持现有 `?demo=1`，但本阶段只做基础适配：

- 隐藏真实账号；
- 竖屏显示课程卡和正文；
- 可以通过 URL 预选课程，例如后续支持：

```text
?demo=1&lesson=fund-risk-01
```

本阶段可以只预留解析，不要求自动播放。

## 自动检查

更新 `check-ai.bat` 或增加独立检查，但不要让原有检查失效。

至少检查：

- `learning-content.js` JavaScript 语法；
- `learning.js` JavaScript 语法；
- 6 节课程 ID 唯一；
- 每节课程有 2 道题；
- 每道题答案索引合法；
- 学习脚本引用的 DOM ID 与页面实际一致。

可以增加：

```text
frontend/learning-smoke-check.js
```

Node.js 不存在时可以跳过 JS 自动检查，但要明确提示。

## 验收流程

必须实际完成以下流程：

1. 启动项目；
2. 登录；
3. 默认进入学习首页；
4. 打开第一课；
5. 阅读内容；
6. 提交两道题；
7. 显示分数和答案解释；
8. 标记课程完成；
9. 返回首页看到进度更新；
10. 刷新页面后进度仍然存在；
11. 点击“查看真实基金”进入现有基金功能；
12. 点击“历史回测实验”进入现有回测功能；
13. 手机 390px 宽度无横向溢出；
14. 原有登录、基金搜索和回测没有被破坏。
