# MarketSim 中国基金 AI 投研产品路线

## 产品定位

面向普通投资学习者的中国公募基金与 A 股模拟研究工具。核心流程是：

```text
真实公开数据 -> 多 Agent 独立分析 -> 风控约束 -> 组合经理结论 -> 历史回测 -> 模拟持仓复盘
```

产品不连接券商、不自动下单、不承诺收益。所有结论必须能追溯到数据、规则和原文来源。

## 与 ai-hedge-fund 的对应关系

| ai-hedge-fund | MarketSim 中国市场版本 |
|---|---|
| Fundamentals Agent | 基金质量 Agent：收益、回撤、夏普、经理、规模 |
| Technicals Agent | 净值趋势 Agent：均线、动量、回撤位置 |
| Sentiment Agent | 中国市场资讯 Agent：政策、行业、市场情绪、原文 |
| Valuation Agent | 估值与拥挤度 Agent：指数估值、行业位置、短期热度 |
| Risk Manager | 风控 Agent：波动、回撤、数据质量、仓位上限 |
| Portfolio Manager | 组合经理：汇总支持和反对证据，不直接执行交易 |
| Investor personas | 中国基金经理公开投资风格模型 |

## 风格模型边界

使用“价值均衡、产业成长、逆向回撤、宏观配置”等公开方法论抽象。不得冒充真实基金经理，不得使用真实姓名暗示本人参与或背书。页面固定显示：

> 依据公开投资方法论抽象，不代表任何真实基金经理本人观点或背书。

## 版本顺序

### V1：可解释投研会议

- 5 个基础 Agent；
- 3 个中国基金经理风格模型；
- 支持证据、反对证据、数据缺口；
- 数据源与更新时间；
- 基金历史净值回测；
- 手机端和视频演示模式。

### V2：真实组合学习

- Agent 读取用户模拟持仓；
- 区分未持有、已持有、盈利和亏损状态；
- 组合层行业暴露、集中度和相关性；
- 每日复盘而不是机械每日买卖；
- 决策版本留痕，事后验证当时依据是否有效。

### V3：中国市场数据增强

- 基金季报持仓与变动；
- 基金经理任职区间业绩；
- 指数估值分位；
- 行业资金流和拥挤度；
- 北向、ETF 份额、融资余额等公开市场指标；
- 多数据源一致性检查与数据质量评分。

### V4：内容与商业化

- 一键生成 9:16 分析卡和视频脚本；
- 买卖点、Agent 分歧和回测曲线动画；
- 免费版：搜索、基础走势、每日有限次数分析；
- 会员版：多风格模型、组合复盘、策略对比、历史报告；
- 创作者版：无隐私演示模式、封面和口播摘要导出。

## 小红书视频模板

```text
1. 输入一只基金代码
2. 五个 Agent 分别给证据
3. 三种中国基金经理风格出现分歧
4. 组合经理给出结论和仓位纪律
5. 用历史回测检查这套方法
6. 展示最大回撤和免责声明
```

标题应突出工具和方法，不突出“赚了多少”。避免“稳赚、必涨、抄底、内部消息”等表述。

## 阿里云部署建议

- 第一阶段：轻量应用服务器或 ECS，Docker Compose 部署；
- Nginx 提供 HTTPS 和静态资源；
- FastAPI 使用多 worker，但定时任务必须拆成单独进程，避免重复执行；
- SQLite 只适合试用，开放注册前迁移 PostgreSQL；
- Redis 用于行情与资讯缓存、限流；
- 密钥只放服务器环境变量，不进入 Git；
- 用户密码继续使用不可逆哈希，Token 设置有效期并支持撤销；
- 增加用户协议、隐私政策、风险提示和数据来源说明。

## 收费前必须完成

- 数据源授权和稳定性确认；
- 备案、域名、HTTPS；
- 用户数据隔离、备份和恢复演练；
- 支付回调验签和订单审计；
- 限流、防刷和日志脱敏；
- 不将规则输出包装成持牌投资顾问服务；
- 对“实时”“AI”“推荐”等措辞进行合规审查。
