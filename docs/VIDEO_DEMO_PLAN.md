# 小红书 / 抖音视频演示方向

本文件用于给 MarketSim 的后续发布、录屏和内容运营预留方向。

项目定位应始终保持为：

> AI 辅助的基金历史净值分析与模拟回测工具，仅用于学习和研究，不连接券商、不执行真实交易、不构成投资建议。

## 已预留的演示模式

普通使用地址：

```text
http://127.0.0.1:8000
```

录屏演示地址：

```text
http://127.0.0.1:8000/?demo=1&fund=014855&focus=1
```

参数说明：

- `demo=1`：开启演示模式；
- `fund=014855`：预填演示基金代码，可替换成其他 6 位基金代码；
- `focus=1`：聚焦模式，只突出回测结果和曲线，减少录屏干扰；
- `autorun=1`：登录后自动发起一次回测，网络或数据源不稳定时不建议使用。

也可以直接双击：

```text
start-demo.bat
```

演示模式会：

- 把账号名称替换为“演示账号”；
- 隐藏退出、刷新和接口状态等无关按钮；
- 自动聚焦“AI 基金回测”页面；
- 优化窄屏和竖屏布局；
- 添加“演示模式 · 非投资建议”标识；
- 不生成虚假收益数据，仍然使用真实公开历史净值或前端规则回测结果。

## 建议的视频内容结构

### 方向一：15 秒功能展示

适合做第一条作品或快速展示。

镜头顺序：

1. 开头 2 秒：输入基金代码；
2. 中间 3 秒：点击“开始回测”；
3. 中间 5 秒：展示收益率、最大回撤、交易次数；
4. 后面 3 秒：展示资产曲线；
5. 结尾 2 秒：显示“历史回测不代表未来收益”。

建议标题方向：

```text
我用 AI 做了一个基金回测网页
```

```text
输入基金代码，就能查看历史策略回测
```

```text
不会写代码，也能用 Codex 做一个基金分析工具吗
```

### 方向二：30～45 秒开发过程

适合展示项目门槛和 Codex 辅助开发过程。

镜头顺序：

1. 展示旧版 MarketSim；
2. 展示 Codex 修改代码；
3. 展示新增的“回测”入口；
4. 输入基金代码；
5. 展示回测结果；
6. 简要说明使用了历史净值、均线和回撤风控；
7. 强调只是模拟研究工具。

内容重点：

- 不要只展示结果，要展示“输入 → 分析 → 结果 → 风险”；
- 可以展示 VSCode、Codex 和最终网页之间的转换；
- 不要把重点放在某只基金赚了多少；
- 应把重点放在“工具如何帮助验证策略”。

### 方向三：60～90 秒教程

适合后续做系列内容。

可以拆成：

1. 如何拉取项目；
2. 如何启动本地网页；
3. 如何输入基金代码；
4. 如何理解总收益率；
5. 如何理解最大回撤；
6. 为什么历史回测不能代表未来；
7. 如何修改策略参数。

## 建议的视频画面重点

优先拍摄：

- 基金代码输入框；
- “开始回测”按钮；
- 最终资产；
- 总收益率；
- 最大回撤；
- 交易次数；
- 资产曲线；
- 每次买卖原因。

尽量不要在视频里长时间展示：

- 登录账号；
- 本地文件路径；
- GitHub Token；
- API Key；
- 邮箱；
- 内网地址；
- 真实持仓和真实资金；
- 浏览器收藏栏中的私人信息。

## 竖屏录制建议

推荐浏览器窗口宽度：

```text
430px ～ 520px
```

推荐视频比例：

```text
9:16
```

推荐录制流程：

1. 先启动 `start-demo.bat`；
2. 登录测试账号；
3. 把浏览器缩窄到手机比例；
4. 使用 `focus=1` 隐藏详细表格；
5. 点击回测；
6. 等结果完全加载后再开始正式录制；
7. 录制时重新点击一次，保证操作过程连贯。

## 封面方向

封面文字应简短，建议控制在两行。

可选文案：

```text
AI 基金回测工具
我自己做出来了
```

```text
输入基金代码
自动生成回测曲线
```

```text
Codex 能帮普通人
做完整 Web App 吗
```

封面画面建议：

- 左侧放基金代码输入框；
- 右侧放收益曲线；
- 中间放“AI 回测”或“Codex 开发”；
- 不要把单只基金的高收益数字作为主要卖点。

## 后续适合开发的视频功能

为了提高后续内容表现力，可以继续增加：

1. 一键生成回测结果分享卡；
2. 导出 PNG 长图；
3. 同一基金多策略对比；
4. 定投与一次性买入对比；
5. 不同仓位上限对比；
6. 回测过程动画播放；
7. 每次买卖点在曲线上标记；
8. 一键复制视频口播摘要；
9. 示例基金列表；
10. 数据源状态和更新时间展示。

优先级建议：

```text
分享卡 > 买卖点标记 > 多策略对比 > 回测动画 > 自动口播摘要
```

## 内容安全边界

所有公开展示应避免：

- “稳赚”；
- “保证收益”；
- “必涨”；
- “跟着买”；
- “无风险”；
- 使用历史最高收益误导观众；
- 隐藏回撤、费用或数据区间；
- 把规则策略包装成真正的人工智能预测。

页面和视频中建议持续保留：

```text
历史回测不代表未来收益，仅供学习和模拟研究，不构成投资建议。
```

## 留给 Codex 的演示模式检查

Codex 最后联调时应检查：

1. 普通地址不加载演示样式；
2. `?demo=1` 会加载 `demo-mode.css` 和 `demo-mode.js`；
3. 演示模式不会显示真实用户名；
4. `focus=1` 会隐藏交易详情和资产明细表；
5. `fund=xxxxxx` 会正确预填基金代码；
6. `autorun=1` 只自动运行一次；
7. 手机宽度下表单和结果卡不溢出；
8. 所有演示结果仍来自真实公开数据或明确标记的模拟回测；
9. 页面始终保留非投资建议提示。
